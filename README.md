# Homebrew Tap for Phantom Secrets

## Install

```bash
brew tap ashlrai/phantom
brew install phantom
```

This tap installs Phantom Secrets `v0.6.0` from the verified prebuilt release
assets published by [`ashlrai/phantom-secrets`](https://github.com/ashlrai/phantom-secrets/releases).

The unified Ashlr tap also carries the same formula:

```bash
brew install ashlrai/ashlr/phantom
```

## About

[Phantom Secrets](https://github.com/ashlrai/phantom-secrets) prevents AI coding agents from leaking your API keys.
